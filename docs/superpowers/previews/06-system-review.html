07 · 风险与决策记录
🛡 安全风险：Vault「导出至本地」
实现"导出至本地"功能时，必须二次确认弹窗（明确说明导出内容范围 + 明文警告）。建议提供加密导出选项（密码加密 JSON），禁止静默导出明文文件。导出操作需要在操作日志里记录时间戳，便于审计。
⚠️ UX 风险：Vault 显示态自动隐藏计时器
Preview 中提及"显示后 30 秒自动隐藏"。实现时需要在 UI 上显示倒计时（而非静默隐藏），给用户操作窗口，防止复制被截断。
✓ 架构决策：工作台不再使用 Section 卡片
v1 工作台采用 Free Studio 方向（打开即写 + Slash 插入块），现有 /workspace 的 Section 卡片 UI 将在迁移后废弃。实现时可先并行保留旧路由，验收 Free Studio 后再删除。
✓ 架构决策：信息流向单向，Inbox 是唯一收集入口
灵感收藏是所有原始素材的唯一入口。工作台、自媒体、首页均不直接收集原始内容，只消费/引用已整理内容。实现时注意不要在这些板块里加"快速记录"功能，防止边界扩散。
⚠️ 移动端：工作台 / 自媒体需要专项设计
这两个板块在 Preview 里只给出了折叠方向，移动端具体交互（工作台 Slash 键盘适配、自媒体左右栏切换 Tab）需要在 Implementation Plan 里单独拆任务。
