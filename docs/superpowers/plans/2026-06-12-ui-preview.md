# Plan: Product UI System v1 — UI Preview

**Date:** 2026-06-12  
**Spec:** [docs/superpowers/specs/2026-06-12-product-ui-system-v1-design.md](../specs/2026-06-12-product-ui-system-v1-design.md)  
**Execution:** 顺序推进，每个 Preview 完成后暂停验收，确认通过再进下一个  
**输出目录：** `docs/superpowers/previews/`（静态 HTML，不修改任何业务代码）

---

## 目标

在进入代码实现之前，用静态 HTML 把 5 个板块的 UI 设计意图具象化，形成可验收的视觉原型。  
验收通过的 Preview 将作为后续每个板块 Implementation Plan 的视觉基准。

---

## 限制（硬约束）

- **不修改** 任何 `app/` 目录下的业务代码
- **不修改** 现有路由：`_index.tsx`、`workspace._index.tsx`、`dashboard-demo.tsx`
- **不修改** `app/components/Sidebar.tsx`
- **不修改** 数据库或 schema
- 所有产出物为独立 HTML 文件，使用内联 Tailwind CDN + inline `<style>`，无需构建

---

## 视觉系统基准（每个 Preview 都遵循）

| 项目 | 规格 |
|---|---|
| 背景 | `#F7F5F0`（米白纸感） |
| 主色 | `#1A7A4A`（深绿） |
| 强调色 | `#D4820A`（琥珀） |
| 辅助色 | 柔和蓝 `#3B82F6`、玫瑰 `#F43F5E` |
| 字体 | system-ui / -apple-system |
| 卡片 | 白色 `#FFFFFF`，`rounded-2xl`，`shadow-sm`，无描边或 `border border-gray-100` |
| 边框 | 最少化，优先用留白区分区域 |
| Sidebar | 固定 180px，复用现有视觉（白底 + 深绿高亮） |

## 执行规则

1. 每个 Preview 独立一个 HTML 文件，使用 Tailwind CDN，内联所有样式
2. 使用虚构数据填充内容（任务名、习惯名、数字等），数据要真实感
3. 每个 Preview 写完后**暂停**，用 `preview_start` 或直接打开 HTML 验收
4. 验收通过后再进下一个
5. Preview 1–5 全部验收通过后，再做 Preview 6 综合 Review
6. **Preview 6 验收通过后，进入讨论：基于视觉稿决定 Implementation Plan**
